## 실제 파일 및 브라우저 확인

이후 배포 전 추가 검증에서는 와디즈 테스트 55/55가 통과했습니다. 실제 미디어/정지 이미지/카피/참조 해시와 검수 승인 연결, 계획 참조 누락, 미완성 거래 조건, API 전용 pin 계약의 오인 방지, 설치용 ZIP 무결성 검사가 추가되었습니다. 설치 ZIP을 새로운 격리 폴더에 풀고 `npm ci` 및 실제 기획 명령을 실행했으며 스킬 구조 검사도 통과했습니다. sangse의 실제 브리지가 와디즈 소스 설치를 찾아 계획을 생성하고, 미확인 생성 작업 16개는 모두 `blocked`로 남는 연결도 확인했습니다.

첫 원격 CI는 Node 20.9 의존성의 `import ... with` 문법 및 Windows 경로 별칭 처리에서 실패했습니다. 그 결과를 숨기지 않고 현재 릴리스의 지원 최소 버전을 Node 22.0.0으로 정정했으며, 가져오기 출력 경로의 기존 조상 실경로를 확인해 DOS 별칭·junction 및 `..nested` 자식 경로도 원본 내부 쓰기로 판정하도록 수정했습니다. 최종 릴리스 검증은 Node 22/24의 Windows/Linux CI를 기준으로 합니다.

`output/integration-verification/`은 판매 상품이 아닌 **도형 기반 파이프라인 검증용 fixture**입니다. 11개 섹션과 GIF 1개를 납품 ZIP으로 조립했습니다. GIF는 640×400, 5프레임, 서로 다른 프레임 3개, 10,468바이트이며 무한 반복·동일한 반복 경계가 측정되었습니다.

로컬 HTTP 미리보기를 390×844와 860×844에서 확인했습니다. 이미지 11개와 GIF가 로드되고 가로 넘침은 없으며 거래 조건이 표시됩니다. 콘솔의 유일한 리소스 오류는 `favicon.ico` 404입니다. 이 확인은 상품 외형·성능·사실의 수동 검수를 대신하지 않습니다. fixture의 게시 상태는 의도적으로 `blocked`입니다.

## 검증하지 않은 항목과 실행 전 조건

자체 이미지 도구에는 모델 고정 파라미터가 없고, 로컬 ima2 3.10.0에서는 실행 가능한 GPT Image 2.5 지원이 확인되지 않았습니다. 배포 준비 과정에서 npm의 최신 ima2-gen 3.26.2도 격리 실행해 capability 및 gen/edit 도움말을 재확인했습니다. 최신 버전의 2.5 명시적 선택 항목 `--image-tool-model`은 API 전용이며, OAuth의 `--model`은 추론 모델 선택 항목입니다. 따라서 이번에 합의한 비별도-API 경로에서는 실제 2.5 고정 생성·편집이 여전히 보류 상태입니다. 개인 전역 ima2 설치·설정은 변경하지 않았습니다. 테스트의 모델 응답은 명시적인 mock이며 실제 생성의 증거가 아닙니다. 별도 API나 다른 모델로 대체하지 않습니다.

실제 제작에는 판매자의 상품 기준 이미지·공식 사실/출처·옵션/가격/거래 조건, 해당 페이지에 관련된 OpenCrab 원문, 카피 승인, 확인된 2.5 실행 환경, 예상 사용량·범위에 대한 승인, 최종 수동 상품/카피/GIF 검수가 필요합니다. 실제 제품의 이미지/GIF 생성과 외부 게시·배포는 이번 구현 검증에 포함되지 않습니다.
