# v0.3.0

이 버전은 상품별 상세페이지 기획·이미지·GIF·납품을 하나의 설치 가능한 스킬로 묶습니다. 공개 게시 상태와 실제 생성 검증은 배포한 릴리스 및 실행 환경에서 따로 확인합니다.

## 변경 사항

- sangse의 구매 질문·인터뷰·스타일·카피 슬롯·정량 출처 검사를 통합했습니다. 식품·뷰티·테크·패션·리빙·서비스와 선물·문제 해결·신제품·프리미엄·비교·재출시를 조합하며 12/15컷은 호환 프리셋입니다.
- OpenCrab 원문 관련성·출처 검증과 미확인 근거 차단을 추가했습니다. 다른 상품의 수치·후기는 현재 상품의 사실로 사용하지 않습니다.
- 자체 이미지 도구/ima2의 실제 GPT Image 2.5 지원과 참조 전달을 검사합니다. 지원을 확인할 수 없으면 작업을 보류하며 API/구형 모델 대체를 하지 않습니다.
- 생성한 텍스트 없는 장면 위에 정확한 한국어·가격·규격·정책의 editable SVG 패널을 합성합니다. 원본 생성 출처와 합성·카피·폰트 해시를 보존합니다.
- 이미지 프레임/실사 영상의 실제 GIF, poster, 순서별 미리보기, QA·manifest·ZIP 납품을 연결했습니다. 실제 성능 증명에는 실사 근거를 사용합니다.
- 기존 sangse 문서·거래 조건·이미지 작업을 새 폴더로 가져오고 변환 한계를 기록합니다. MIT 고지를 보존합니다.

## 설치·환경

Node.js 20.9.0 이상이 필요합니다. 설치 ZIP에는 `wadiz-detail-page-production/` 아래 리소스·라이선스·`release.json`·`PACKAGE-MANIFEST.json`·`SHA256SUMS`가 포함됩니다. ZIP 전체 체크섬은 함께 배포하는 `.zip.sha256` 파일입니다. 의존성은 설치 후 `scripts/`에서 `npm ci`로 준비하며, GIF에는 FFmpeg/FFprobe, 한국어 합성에는 실제 한국어 글리프를 가진 폰트가 필요합니다.

릴리스 설치 명령은 [README](../../README.md)를 참고하세요. OpenCrab 팩/인증, 개인 스킬 설치, 실제 이미지 생성과 와디즈 업로드는 ZIP 설치로 자동 수행되지 않습니다. 유료 생성 범위와 최종 결과 검수는 기존 워크플로를 따릅니다.

이번 배포 준비에서는 GPT Image 2.5의 실제 생성 성공을 확인하지 않았습니다. 자체 이미지 도구의 공개 계약에는 모델 고정 확인이 없고, 조사한 ima2 3.26.2의 `--image-tool-model` 2.5 지정은 API 경로용입니다. 합의한 OAuth/계정 경로에서 2.5 고정과 참조 전달을 입증할 수 있을 때 실행합니다. 설치된 버전·모델 목록만으로 지원을 선언하거나 별도 API로 바꾸지 않습니다.

## 제작·검증

배포 준비 로컬 검증: 와디즈 회귀 테스트 55/55, 설치 ZIP 114개 파일의 CRC/SHA-256 및 새 폴더 설치·의존성 설치·기획 실행 검증 통과. 실제 생성은 수행하지 않았습니다. 원격 CI 결과는 연결된 GitHub Actions 및 PR에서 확인합니다.

```powershell
node wadiz-detail-page-production/scripts/package-skill.mjs --out output/wadiz-detail-page-production-v0.3.0.zip
node wadiz-detail-page-production/scripts/package-skill.mjs --verify output/wadiz-detail-page-production-v0.3.0.zip
```

패키저는 Node 내장 기능만 사용하고 허용한 리소스만 담습니다. 기존 출력·symlink/junction을 거절하며 의존성, 인증 파일, 실행 산출물을 제외합니다. 원본 파일·체크섬 manifest·ZIP의 실제 CRC/SHA-256를 대조합니다. Windows/Linux CI는 한국어 폰트·FFmpeg를 준비하고 `npm ci`, 테스트, 패키지·표준 ZIP·스킬 구조 검사를 수행합니다. CI 구성 추가와 원격 CI 통과는 별개의 결과입니다.
