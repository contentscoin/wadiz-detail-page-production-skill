# Legacy combined beauty / food / health routing

This file preserves the former `beauty-food-regulated` reference. New projects must choose [food.md](food.md) or [beauty.md](beauty.md) from the actual product. Health/functional claims need the applicable current product classification and source review; do not assume the old combined label supplies that classification.

Preserve ingredient, certification/test, usage, and caution requirements from imported plans when relevant. Actual certification marks, test results, testimonials and efficacy evidence cannot be generated. Exact ingredient/usage/legal text uses editable deterministic layers. The former 15-cut default is an explicit compatibility preset, not a new planning default.
