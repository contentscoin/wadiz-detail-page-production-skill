# 제품 상세페이지는 홈페이지가 아니다

## Session lesson

A user asked for a 상세페이지, but the first response produced a web route/landing-page style output. The user corrected twice:

- “상세페이지를 만들어달라고”
- “홈페이지가 아니라 제품 상세페이지야”

For ecommerce/Wadiz tasks, this is a workflow correction, not merely a copy tone issue.

## Default interpretation

When the user says any of these:

- 제품 상세페이지
- 상품 상세페이지
- 상세페이지 이미지
- 서비스 상세페이지
- 이커머스 상세페이지
- ecommerce detail page
- 와디즈 상세페이지
- 상품 상세
- 마켓 상세페이지

Default to **cut-based product detail-page assets**, not a website/homepage.

## Correct deliverable shape

Unless the user explicitly requests a web page, produce or plan:

1. Exact cut count, usually 12 or 15 cuts.
2. Individual cut images, default 1080×1600.
3. Optional long detail image, e.g. 1080×19200 for 12 cuts.
4. Contact sheet for quick QA.
5. Gallery HTML only as a preview wrapper.
6. ZIP package containing cuts, long image, QA report, and manifest.
7. QA on image dimensions, count, Korean text readability, claim safety, and ZIP integrity.

## What not to do

- Do not answer with only a `/detail` route.
- Do not call a homepage/landing page a product detail page.
- Do not expose internal planning language such as `fact map`, `QA`, `VISUAL DIRECTION`, `publication`, or `컷 구성` in the customer-facing final images.
- Do not produce a generic service landing page with navbar, sections, and CTA as the main artifact.
- Do not present HTML as the final asset unless the requested channel is specifically a website.

## Useful pattern

For a service-like product such as premium golf/VIP membership/consulting, a product detail page can still be image-based:

- Hero promise
- Customer problem
- Core package/offer
- How the service works
- Use scenes
- Proof/network/team
- FAQ/objection handling
- Caution/scope notes
- Final CTA

Keep public-facing copy customer-oriented and remove internal workflow labels.

## Completion wording

Say clearly:

- `제품 상세페이지 컷 이미지로 제작했습니다.`
- `웹 route는 미리보기용입니다.`
- `publication_status: review_required` if facts, legal/terms, exact offer, or final brand approval remain unconfirmed.
