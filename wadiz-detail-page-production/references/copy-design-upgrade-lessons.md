# Copy + Design Upgrade Lessons for Wadiz Detail Pages

Use this reference when a user says the detail page is "일률적", "내용이 부실", "카피라이팅과 디자인을 다시", or similar.

## Durable lesson

A valid 12/15-cut package is not enough. The page must have distinct persuasive jobs per cut and visibly different layout families. If the user complains about uniformity or weak content, treat the previous draft as a structural failure, not a minor styling issue.

## Required repair pattern

1. **Reposition the offer before regenerating visuals.** Rewrite the product from a customer decision frame, not from internal product facts. For FMGS/CEO Golf-like offers, frame as executive time reduction and operating support, not merely a lesson coupon.
2. **Increase copy density safely.** Each cut needs a clear buyer question, objection, proof, offer detail, or next action. Avoid generic one-line descriptions repeated across cards.
3. **Use different layout families by cut role.** Mix hero, problem cards, price/offer reveal, timeline, motion storyboard, proof dashboard, scene stack, comparison table, tier/module structure, network/proof map, profile/matching cards, FAQ, notice, and CTA.
4. **Do not put internal QA labels in customer-facing images.** Terms like `publication blocked`, `pack_verified`, `concept-only`, and risk notes belong in docs/QA reports. Rendered cuts may include natural customer-safe caution copy only.
5. **Keep Korean text deterministic.** Generate text-free backgrounds when using image models; add Korean headlines, prices, URLs, CTA, logo, and legal copy with deterministic composition.
6. **Patch weak cuts immediately after visual QA.** If QA finds repeated filler copy (for example repeated timeline body text), fix and repack before reporting completion.
7. **Use official URL/logo when provided.** Verify the URL live when possible; update CTA and contact cuts. If the logo source has a background or low resolution, use it as a badge and state that transparent PNG/SVG is still preferred for final publication.

## Minimum QA before delivery

- 15/15 or requested cut count exists.
- Every cut has the target dimensions.
- Contact sheet, long image, gallery/ZIP are regenerated after fixes.
- ZIP integrity check passes.
- Vision/manual QA confirms no obvious text overlap, broken Korean, or missing cuts.
- Remaining publication blockers are separated from customer-facing cuts and reported in final notes.
